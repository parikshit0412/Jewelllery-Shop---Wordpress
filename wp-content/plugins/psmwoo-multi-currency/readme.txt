== External Services ==

This plugin connects to Yahoo Finance to fetch live exchange rates, which are securely stored in your database and used for real-time price conversions.

- **Service:** Yahoo Finance
- **Purpose:** Retrieving up-to-date exchange rates for accurate currency conversion.
- **Data Sent:** Only the currency symbols for the base and target currencies (e.g., USD to EUR) are transmitted.
- **Frequency:** When you add a new currency, update currency settings, or manually refresh exchange rates.
- **Terms:** https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html
- **Privacy Policy:** https://legal.yahoo.com/us/en/yahoo/privacy/index.html

No personal or sensitive information is ever sent—only public financial data is accessed for conversion calculations.

== Installation ==

Installing the plugin is simple:

**1. From Your WordPress Dashboard (Recommended)**

1.  Navigate to `Plugins` > `Add New`.
2.  In the search bar, type "**Multi Currency Switcher for WooCommerce - PSM Plugins**".
3.  Find the plugin and click `Install Now`.
4.  Once installed, click `Activate`.
5.  Find the plugin settings under the `PSM Plugins` menu to begin configuration.

**2. Manual Upload**

1.  Download the plugin's `.zip` file from this page.
2.  Navigate to `Plugins` > `Add New` in your WordPress dashboard and click the `Upload Plugin` button.
3.  Select the `.zip` file you just downloaded and click `Install Now`.
4.  Activate the plugin.
5.  Find the plugin settings under the `PSM Plugins` menu to begin configuration.

For a detailed setup guide, please see our [documentation](https://docs.psmplugins.com/docs/psm-multi-currency/).

== Frequently Asked Questions ==

Here are answers to some common questions about our **multi currency switcher**.

= 1. How do I add multiple currencies to WooCommerce using this plugin? =

It's simple. After installing, go to the plugin settings, and you can add any currency you need from a comprehensive list. You can configure each one's display format, exchange rate, and more.

= 2. How can I display the currency switcher on my site? =

You have total flexibility. You can place the **currency switcher** anywhere using our:
* Native Gutenberg currency block
* Easy-to-use Elementor currency widget
* Versatile currency switcher shortcode

= 3. How are exchange rates updated? Can I set my own? =

Both. You can get real-time exchange rates with a single click, or you can set custom exchange rates for WooCommerce manually to have full control over your pricing and protect your profit margins.

= 4. Can customers actually pay in different currencies? =

Yes. Our plugin enables a true multi currency checkout. The local currency a customer selects is what they'll see on the cart, checkout page, and pay with through your payment gateway.

= 5. Does this work with my payment gateway (e.g., Stripe, PayPal)? =

Yes, it's compatible with all major payment gateways that support multiple currencies. You can even assign payment gateways per currency, so customers only see the options relevant to them.

= 6. Does the plugin automatically detect a visitor's currency? =

Yes, this powerful feature is available in our Pro version. The automatic currency detection by country uses geolocation currency technology to instantly show visitors prices in their local currency.

= 7. Is the plugin compatible with WooCommerce Subscriptions? =

Absolutely. Our plugin is fully compatible with WooCommerce Subscriptions currency logic, so you can easily accept recurring payments in multiple currencies.

= 8. Can I use this for a multilingual and multi-currency store? =

Yes. We built our plugin to be fully compatible with the most popular multilingual solutions. You can create a powerful WPML multi currency or Polylang multi currency site with ease.

= 9. Will this currency converter slow down my website? =

No. Performance is a top priority for us. Our plugin is lightweight and works well with popular caching plugins to ensure your store remains fast.

= 10. What is the main difference between the free and Pro versions? =

The free version gives you all the essential manual tools. The Pro version adds powerful automation, like geolocation and scheduled rate updates, to put your global store on autopilot.
